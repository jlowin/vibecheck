# vibecheck

vibecheck is a tiny Python control-flow primitive over decision models such as Jev. Anywhere ordinary Python needs an AI judgment, that judgment is one function call. It is not an agent framework.

**Product principle:** minimum ceremony for putting probabilistic judgment into ordinary Python.

`README.md` is a working-backwards spec: it describes the package as if it already shipped. Treat it as the source of truth for the intended API, and change the README first when the design changes.
